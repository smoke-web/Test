# Шаблоны для Direct

Цель переписки — **короткий созвон** (10–15 минут). Продажа происходит там, а не в чате.
Отвечайте в течение часа: чем быстрее ответ, тем выше шанс заказа.

## 1. Человек написал «САЙТ» / «Хочу сайт»
```
Здравствуйте, [Имя]! Спасибо, что написали 🙌
Чтобы предложить подходящий вариант, подскажите:
1. Чем вы занимаетесь?
2. Есть ли сейчас сайт?
3. Что главное должен делать сайт: заявки, онлайн-запись, продажи?
```

## 2. После ответов: переход на созвон
```
Понял, спасибо! Для [ниша] обычно хорошо работает [лендинг с онлайн-записью / сайт-визитка с портфолио].
Предлагаю созвониться на 10–15 минут: покажу примеры и назову точную цену и сроки.
Когда удобно: сегодня в [время] или завтра в [время]?
```

## 3. «Сколько стоит?» (без деталей)
```
Здравствуйте! Лендинг от [цена] ₽, сайт-визитка от [цена] ₽.
Точная цена зависит от задачи. Расскажите в двух словах, чем занимаетесь, и я сразу сориентирую по стоимости 🙂
```

## 4. «РАЗБОР» (лид-магнит)
```
Здравствуйте! Пришлите ссылку на ваш сайт (или страницу, куда сейчас ведёте клиентов).
В течение [24 часов] запишу видеоразбор: что мешает получать заявки и как это исправить.
```
После отправки разбора:
```
Готово, отправил разбор 👆 Самое важное: [1–2 ключевые ошибки].
Если захотите, исправлю всё это под ключ за [N] дней. Удобно обсудить на коротком созвоне?
```

## 5. Работа с возражениями
**«Дорого»**
```
Понимаю. Давайте посчитаем: если сайт приносит хотя бы [2] клиентов в месяц со средним чеком [X], он окупается за [N] месяцев.
Можно начать с минимальной версии за [цена] и дорабатывать потом. Можно оплатить частями: 50/50.
```
**«Подумаю»**
```
Конечно! Подскажите, что важно взвесить: цену, сроки или результат? Отвечу на любые вопросы.
Кстати, на [месяц] у меня осталось [2] места.
```
**«Сделаю сам на конструкторе»**
```
Отличный вариант, если есть время! Обычно это 20–40 часов на освоение и сборку.
Если хотите, пришлю чек-лист, что обязательно должно быть на сайте, чтобы он приносил заявки.
```

## 6. Напоминание, если человек пропал (через 2–3 дня)
```
[Имя], здравствуйте! Подскажите, актуален ещё вопрос с сайтом?
Если удобно, держу для вас место на [дата].
```
Не больше двух напоминаний.

## 7. После созвона
```
Спасибо за разговор! Как договорились:
— [тип сайта], [основные блоки]
— Срок: [N] дней
— Стоимость: [цена] ₽ (50% до старта, 50% после сдачи)
Высылаю договор и бриф. Начнём, как только получу предоплату.
```

## 8. После сдачи проекта: просьба об отзыве
```
[Имя], рад, что всё получилось! Можете написать пару слов о работе? Отзыв очень поможет мне 🙏
Если порекомендуете меня знакомым, подарю [месяц поддержки / скидку] на следующий проект.
```
